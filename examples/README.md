# Synthetic layout examples

These files are generated from tests/fixtures.py, using an offline orchestration
double. They illustrate the static output layout and are not real provider-validated
projects. All hosts, identities and numeric IDs are fictional. Do not run their
imports against a live organization. They contain no user inventory or credentials.

The input model and fake provider bodies are intentionally small. Real generation
uses the selected provider to hydrate discovered imports and validate its output.
